A estrutura básica de uma página em html consiste em elementos como, titulo, corpo e rodapé devidamente estruturados para que o site funcione corretamente e facilite a navegação do usuário. As tags a baixo por exempro são utilizadas para estruturar uma página web, cada uma com sua função específica.

    tags: representam os elementos que compõem a estrutura de uma página HTML.
    heade: Representa o cabeçalho de uma página ou de uma seção. Normalmente contém o título, logotipo, informações introdutórias e o menu de navegação.
    main: Representa o conteúdo principal de uma página.
    section: Representa uma seção em uma página, geralmente contendo um título e um conjunto de elementos relacionados.
    footer: Representa o rodapé de uma página ou de uma seção.
